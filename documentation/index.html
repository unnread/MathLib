MathLib

Small math helpers for C++.

Getting started

Clone the repository, then include the headers you need:

#include "include/math.hpp"
#include "include/conversion.hpp"

For example, save this as main.cpp in the repository root:

#include "include/math.hpp"
#include "include/conversion.hpp"
#include <iostream>

int main()
{
    std::cout << math::add(5, 10) << '\n';
    std::cout << math::hypotenuse(3, 4) << '\n';
    std::cout << KmToM(2) << " meters\n";
    std::cout << KgToG(2) << " grams\n";
    std::cout << CelsiusToFahrenheit(20) << " Fahrenheit\n";
}

Compile it with a C++17 compiler:

g++ -std=c++17 main.cpp -o mathlib-demo

Functions

FunctionWhat it does
add(...)Adds the supplied values.
subtract(a, ...)Subtracts the remaining values from the first.
multiply(...)Multiplies the supplied values.
divide(a, ...)Divides the first value by the product of the remaining values.
square(n), power(n, p)Calculates a square or a power.
squareRoot(n)Returns the square root.
distance(x1, y1, x2, y2)Distance between two points.
hypotenuse(a, b)Hypotenuse for the given sides.
sine(a), cosine(a), tangent(a)Trigonometric functions; angles are in radians.
degreesToRadians(d), radiansToDegrees(r)Converts between degrees and radians.
factorial(n)Calculates the factorial of a non-negative integer.

Length

Include conversion.hpp for conversions between kilometers (km), hectometers (hm), decameters (dam), meters (m), decimeters (dm), centimeters (cm), and millimeters (mm). For example: 

#include "include/conversion.hpp"

int meters = KmToM(2);       // 2000
int centimeters = MToCm(3); // 300
int kilometers = CmToKm(500000); // 5

Weight

Weight conversions are available between kilograms (kg), hectograms (hg), decagrams (dag), grams (g), decigrams (dg), centigrams (cg), and milligrams (mg). 

int grams = KgToG(2);       // 2000
int milligrams = GToMg(5); // 5000
int kilograms = MgToKg(2000000); // 2

Temperature

int fahrenheit = CelsiusToFahrenheit(20); // 68
int celsius = FahrenheitToCelsius(68);    // 20

Conversion functions return integers, so fractional results are truncated.
