MathLib C++

Documentation officielle de MathLib.

Présentation

MathLib est une petite bibliothèque mathématique en C++ permettant de réaliser facilement des calculs courants, de la géométrie et de la trigonométrie.

Installation

Clonez le projet : 

git clone https://github.com/unnread/MathLib.git

Ajoutez ensuite le fichier : 

#include "math.hpp"
dans votre projet C++.

Compilation

Avec g++ : 

g++ main.cpp -o programme

Linux : 

./programme

Windows : 

programme.exe

Exemple rapide

#include "math.hpp"
#include <iostream>

int main()
{
    std::cout 
        << math::addition(5, 10);

    return 0;
}
Résultat : 
15

Fonctions disponibles

Calculs

  • addition()
  • soustraction()
  • multiplication()
  • division()
  • carre()
  • puissance()
  • racineCarree()

Géométrie

  • pythagoreCalculDistance()
  • pythagoreHypotenuse()

Trigonométrie

  • sinus()
  • cosinus()
  • tangente()

Conversions

  • degresVersRadians()
  • radiansVersDegres()

Exemples

Addition

math::addition(5, 3, 10);

Pythagore

math::pythagoreHypotenuse(3,4);
Résultat : 
5

Distance

math::pythagoreCalculDistance(0,0,3,4);
Résultat : 
5
